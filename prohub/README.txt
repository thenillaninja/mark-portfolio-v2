ProHUB Deployment
=================

Your ProHUB is a static website.

DEPLOY
------

1. Extract prohub-export.zip.
2. Upload ALL files and folders.
3. Keep the folder structure intact.
4. Visit index.html through your public URL.

Example:

https://yourdomain.com/prohub/

QR CODE
-------

If you use ProHUB's generated QR code, the QR destination should
be the final public URL where your ProHUB is hosted.

Example:

https://yourdomain.com/prohub/

If that URL changes, update it in ProHUB Admin and export again.

HOSTING
-------

Compatible with static hosting such as:

- Cloudflare Pages
- GitHub Pages
- Netlify
- shared hosting / cPanel
- standard HTML hosting

The exported public profile does not require a database,
Node.js, PHP, or a server-side application.
